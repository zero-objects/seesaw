# Bekannte Abweichungen der Java-Engine von den Protokollen des Hosts
# zerodds-pde, für den Teil pde von jgate.sh. Eine Zeile je Protokoll:
#   <name> <zeile> <meldung>
# <meldung> ist der Text der PdeReplay$Mismatch zwischen "<datei>:<zeile>: " und "; Aufruf:".
# Für ein Protokoll mit Eintrag besteht der Teil pde nur, wenn die erste Abweichung genau an dieser
# Zeile mit genau dieser Meldung liegt. Jeder Aufruf davor ist dann gegen das Protokoll geprüft.
# Eine frühere oder spätere Abweichung, eine andere Meldung oder ein Lauf ohne Abweichung (eine
# Verhaltensänderung) fallen durch.
#
# Keine Einträge. Java 2.0.2 wich in open2 und open2-edit an Zeile 27636 und in open5 an Zeile 76200
# ab (step: erwartet false, bekommen true): Matcher.buildPlan nahm SAME_VALUE in den Suchplan, Rust
# (src/engine/matcher.rs, build_plan) prüft Wert-Gleichheiten nur als abschließende Bedingung. Seit
# der Behebung (CHANGELOG [Unreleased], "Java: matches missed behind a value equality") laufen
# java40, open2, open2-edit und open5 ohne Abweichung.
